# J9's Canni-Bombs Luxury Relaunch

This branch rebuilds the original one-file black-and-purple brochure into a boutique, conversion-focused bath ritual storefront.

## Included

- Warm ivory, plum, rose, sage, and candlelit visual system
- Three customer-friendly mood collections
- Twenty curated scent profiles
- Ritual and Immersion size pricing
- Three-Mood Immersion Trio
- Interactive product quick views and ritual bag
- Responsive mobile layouts
- Founder story, ritual education, SEO metadata, and AEO-friendly FAQ content
- Private brand-renaming directions
- Wix + Square integration handoff

## Commerce status

The custom ritual bag currently falls back to an email order request. Connect a published Wix/Square store URL in `app.js` using the instructions in `WIX_HANDOFF.md`.

## Review workflow

Review and approve the `luxury-relaunch` pull request before merging into `main`. The current production branch remains unchanged until merge.
